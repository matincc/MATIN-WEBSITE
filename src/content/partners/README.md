# Partners and supporters

One YAML file per organization that really works with or funds Matin, with its written
permission to show its name and logo:

```yaml
name: Ville de Montréal
kind: funder        # partner | funder | sponsor
logo: ../../assets/uploads/partners/ville-de-montreal.png
url: https://montreal.ca/
permission: true
order: 1
```

Hidden while this folder holds only this README. Never list the Resources directory here.
