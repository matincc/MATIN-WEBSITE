# Words of participants

One YAML file per quote, published ONLY with the person's consent, first name only:

```yaml
quote:
  fr: « J'ai rencontré des voisins que je croisais sans jamais leur parler. »
original: fr
firstName: Sara
context:
  fr: Promenade d'automne, novembre 2026
  en: Autumn walk, November 2026
consent: true
order: 1
```

Never invent or rewrite a quote. Hidden while this folder holds only this README.
