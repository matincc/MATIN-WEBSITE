# Careers · Emplois · فرصت‌های شغلی

Shown on the Careers page (`/fr/emplois/`, `/en/careers/`, `/fa/careers/`): paid positions
at Matin (owner's request, Oct 27 2026). One YAML file per position. Volunteering stays on
Contact & Collaboration. Without a published position the page says none is open and still
accepts open applications. Only real positions the owner approved: never a sample.

```yaml
title:
  fr: 'Coordonnateur ou coordonnatrice de projets culturels'
  en: 'Cultural Projects Coordinator'
  fa: 'هماهنگ‌کنندهٔ پروژه‌های فرهنگی'
type: part-time # full-time, part-time or contract
location: montreal # montreal, remote or hybrid
pay: # optional
  fr: '24 $ de l’heure'
  en: '$24 an hour'
  fa: '۲۴ دلار در ساعت'
posted: 2026-11-01
deadline: 2026-11-30 # optional; the position leaves the page after this day
summary:
  fr: 'Une ou deux phrases.'
  en: 'One or two sentences.'
  fa: 'یک یا دو جمله.'
description: # optional, Markdown, shown when the card is opened
  fr: '…'
  en: '…'
  fa: '…'
order: 10
published: true
faReviewed: true
```

Applications arrive through the Netlify form `emplois` (notification email as for the other
forms) and as rows in the Contact tab of the forms Sheet, marked « Candidature · Job
application · درخواست شغل ».
