# International Cultural Networks · Réseaux culturels internationaux

Shown on the Resources page, section « Réseaux culturels internationaux » / "International
Cultural Networks" (#networks). One YAML file per network. **A listing never means that
Matin is a member or a partner**, unless `status` says so with the owner's confirmation.

```yaml
name: 'Name as the network writes it'
nameEn: 'English form' # optional
url: https://example.org/ # official website
logo: ../../assets/uploads/networks/file.png # optional, official logo where permitted
description: # short and factual
  fr: '…'
  en: '…'
scope: International # optional
status: listed # listed (default), member or partner
order: 10
published: true # only once name, website and description are verified
```
